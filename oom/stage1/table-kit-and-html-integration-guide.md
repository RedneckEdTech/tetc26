# TABLE KIT & DIGITAL TERMINAL INTEGRATION GUIDE
**Document Scope:** Technical Navigation, Access Codes, Physical-to-Digital Flow, and Facilitator Protocols  
**Module:** Chamber Stage 1: Muggle Studies (Order of Merlin, Third Class)  
**File Reference:** `stage1_muggle_studies.html`

---

## 1. System Architecture: The Dual-Realm Bridge
The core instructional goal of Stage 1 is teaching **resilient pedagogical architecture**. Educators often experience technology interruptions during classroom instruction. By pairing physical, unplugged tabletop items with a zero-dependency local or web terminal, participants experience how analog mechanics and generative AI complement one another:

* **Physical Table Kit ("The Sorting Envelope"):** 2 D6 dice, blank index cards, sticky notes, markers, Marauder's Map checklist, House Table Tent.
* **Digital Terminal (`stage1_muggle_studies.html`):** Built-in 10-minute timer, dynamic Gemini prompt generator, checklist, and verification gate.
* **Bridge Mechanism:** Teachers select their subject and grade in the terminal to generate a targeted prompt, paste it into Google Gemini, and then physically assemble the resulting game with their tabletop materials.

## 2. How Participants Access `stage1_muggle_studies.html`
To accommodate any school network or device setup, the terminal supports four distinct access methods:

### Method A: Table Tent QR Code (Recommended Mobile / Tablet Path)
1. Each House Table Tent features a high-contrast QR code on Side B.
2. The designated table **Scribe** points their smartphone, tablet, or Chromebook camera at the QR code.
3. The device opens the hosted terminal in their default browser.

### Method B: Hosted GitHub Pages Link (Standard Workshop Path)
1. If hosting the entire workshop repository on GitHub, the URL structure is:
   `https://[username].github.io/[repo-name]/stage1_muggle_studies.html`
2. Display a shortened link (e.g., `bit.ly/merlin-stage1`) on Slide 1 and Slide 4.

### Method C: Offline Thumb Drive or Local Drive (Zero-Internet Safeguard)
1. Because `stage1_muggle_studies.html` has **zero external dependencies** (no external fonts, remote stylesheets, or external scripts), it operates completely offline.
2. Prior to the session, load the file onto 8 USB thumb drives (one per table) or place it in a shared local folder.
3. Participants double-click the file to open it directly in Chrome, Edge, Safari, or Firefox without needing internet access.

### Method D: District LMS or Cloud Portal (Google Drive, SharePoint, Google Sites)
* Upload the file to your district Google Drive, Microsoft SharePoint, or Google Sites repository and share the viewable link with participants.

## 4. Chamber Gate 1: Verification Lock & Access Codes

### How the Lock Functions
At the bottom of `stage1_muggle_studies.html` sits the **Chamber Gate 1: Verification Lock**. The input accepts alphanumeric codes (case-insensitive) and validates them instantly without refreshing the page.

### Thematic Riddle & Valid Codes
The clue provided on the Marauder's Map and Slide 4 reads:  
> *"Combine your 12 challenge cards with your two six-sided dice to forge the cipher that releases the gate."*

* **Primary Master Code:** **`12D6`** *(12 index cards + D6 dice)*
* **Numeric Alternate:** **`1206`** *(12 cards + 06 dice sides)*
* **Lore Backups:** **`MUGGLE`** or **`MERLIN`** *(Built-in facilitator override codes)*

### What Happens Upon Successful Unlock:
1. The terminal displays the animated **Chamber Gate 1 Conquered** celebration banner.
2. A ribbon badge appears confirming **+25 House Points**.
3. The terminal instructs the House to display their physical **White Ribbon** on their table tent.
4. If time remains on the Chamber Clock, it cues the table to request the **Keeper's Bonus Trial #1 (+15 pts)** from the facilitator.

## 5. Facilitator Troubleshooting & Intervention Protocols

### Scenario 1: Participant Camera Cannot Read the QR Code
* **Action:** Instruct the Scribe to type the short URL displayed on Slide 1, or open the local file from the table thumb drive.

### Scenario 2: Table Spends Too Much Time Debating Game Rules Instead of Writing Cards
* **Action:** Intervene using the **5-Minute Rule**: *"Wizards! Do not over-engineer the rulebook. Gemini has provided your 12 cards. Hand 2 cards to each teammate and start writing now so you have a playable game before the clock expires!"*

### Scenario 3: A Table Is Stalled on the Verification Code at the 3-Minute Mark
* **Action:** Deliver a **Felix Felicis ("Liquid Luck") Card**. Point directly to the card's clue: *"Your code is your 12 cards plus your D6 dice: enter 12D6 into the terminal now!"*

### Scenario 4: Fast Finishers Crack the Lock in 6 Minutes
* **Action:** Award the **Speed Bonus** (+10 for 1st, +5 for 2nd, +3 for 3rd) on the live scoreboard. Immediately hand them the sealed **Keeper's Bonus Trial #1 Card** (+15 pts) to brainstorm two classroom adaptations while other tables finish.
